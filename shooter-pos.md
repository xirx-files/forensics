# Forensic Audio Analysis: Triangulation of Acoustic Event

## 1. Objective
To determine the geographic origin of a loud "bang" event captured on multiple video recording devices.

## 2. Methodology: Time Difference of Arrival (TDOA)
The analysis uses Time Difference of Arrival (TDOA). The core formula is: `Distance = (Time_Sound_Heard - Time_Event_Seen) * Speed_of_Sound`.
With distances from multiple known locations, a **Multilateration** algorithm finds the single geographic coordinate that best satisfies all measured distances.

**Environmental Constants:**
- **Speed of Sound:** 349.5 m/s (based on 30°C temperature)
- **Subject Location (Origin):** 40.2775277° N, -111.7140278° W

## 3. Data Analysis and Preparation
- **GPS and VTZ data** was sourced from `README.md`.
- **Audio Clip Offsets** were parsed from `exec-instructions-*.md` files.
- **High-Precision Audio Onsets** for the bang were generated by `onset_analysis.py`.

## 4. TDOA Calculation and Results

- **Data Quality Issues:** Some data points were automatically excluded because their source data produced a negative `delta_t` (implying sound arrived before the visual event), indicating an unresolvable error in their provided VTZ or audio offset times. Specifically, `video-1.mp4`, `video-2.MOV`, `video-3.mp4`, `video-7.mp4`, and `video-8.mp4` were skipped.

The final triangulation was performed using the 7 valid data points:

| Video Source | Calculated Distance to Source |
| :--- | :--- |
| video4.mp4 | 4.57 meters |
| video13.mp4 | 6.66 meters |
| video16.mp4 | 123.12 meters |
| video17.mp4 | 33.50 meters |
| video12.mp4 | 25.38 meters |
| video5.mp4 | 14.78 meters |
| video6.mp4 | 8.42 meters |


A numerical solver minimized the error across these 7 distances.

- **Estimated Location (Local XY): `(x = 34.79m, y = -16.73m)`**
  *(This is relative to the subject at (0, 0))*

## 5. Final Result: GPS Coordinate of Source

The local XY coordinate was converted back to geographic coordinates.

#### The final estimated GPS coordinate for the source of the bang is:

-   **Latitude:** `40.2773771° N`
-   **Longitude:** `-111.7136181° W`

In Degrees, Minutes, Seconds format:
-   **40° 16' 38.558" N**
-   **111° 42' 49.025" W**
