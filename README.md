# Method

there are two methods that are are going to be applied for this forensic analysis:

1. TDOA
this method uses visual time zero of the impact and arrival time of the sound to the recording device to determine distance from the device of the originating sound.

2. delta of the time gap between:
    1. audio event of "violence" ending and audio event "great" beginning (gap A)
    2. audio event of "great" ending and audio event of the loud bang beginning (gap B)

if the time gaps measured are the same for all recorded samples then we know that the PA system with the four speakers were the relayed source
